# Malawi IT Education

IT education program conducted in Malawi for local high school and university students.

## Curriculum

### Excel Education (`excel-education/`)
Introductory spreadsheet course covering practical data skills.

| Folder | Contents |
|--------|----------|
| `lecture-notes/` | Lecture slides (PDF) |
| `practice-files/` | In-class practice files |
| `worksheets/` | Hands-on worksheets |

### Web Development Education (`web-education/`)
5-day web development course from HTML basics to building a complete website.

| Day | Topic |
|-----|-------|
| Day 1 | HTML Basics |
| Day 2 | CSS Layout |
| Day 3 | CSS Design |
| Day 4 | JavaScript |
| Day 5 | Build Your Own Website |
